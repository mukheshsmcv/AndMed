# ANDE MED
## Adaptive Intelligence for Medical Exams

An adaptive medical MCQ platform initially targeting INI-CET and NEET-PG aspirants in India.

### Features
- Adaptive Learning Engine
- Spaced Repetition (Revision Engine)
- Subject & Topic Mastery Tracking
- AI-Powered Explanations

### Tech Stack
- Expo (React Native)
- Supabase (PostgreSQL, Auth)
- Tailwind CSS

### Getting Started
1. Clone the repository
2. Install dependencies: `npm install`
3. Setup environment variables: copy `.env.example` to `.env` and fill in your Supabase details.
4. Start the app: `npx expo start`
